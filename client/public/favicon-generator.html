savyfunds Favicon Generator

Instructions

This tool will generate all necessary favicon files for savyfunds to ensure compatibility with all browsers, especially Microsoft Edge and IE.

  1. Upload your SVG favicon (your current favicon-3d-v2.svg)
  2. Click "Generate Favicons" to create all necessary formats
  3. Download each file and replace the existing ones in your project
  4. HTML code for your website is already updated
